## Bilingual repository and beginner onboarding

- Simplified Chinese is now the default repository landing language, with a complete English README and two-way language navigation.
- The landing page now explains browser use, offline HTML download, local development, GitHub Pages, and Cloudflare Pages for first-time users.
- Chinese and English search phrases describe the real product without promising lossless small-grid conversion.
- Portable builds normalize embedded license text to LF, improving byte-for-byte reproducibility across Windows and Linux.
- The Release ZIP now preserves documentation and screenshot paths instead of shipping disconnected README links.

The conversion algorithm, project format, and palette values are unchanged.

## Integrity

Download `SHA256SUMS.txt` from this Release and verify files against that same Release. Do not compare a file with a checksum from a different tag.
